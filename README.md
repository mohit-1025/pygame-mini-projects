# 🎮 Pygame Mini Projects

A growing collection of **mini projects built with Python and Pygame** — games, tools, and experiments, each kept in its own folder.

Every project here is self-contained: you can open a folder, install Pygame, run `main.py`, and start playing.

## 📁 Repository Layout

Each top-level folder is a separate Pygame project with its own source code, assets, and README.

```text
pygame-mini-projects/
├── <project-1>/
│   ├── main.py
│   ├── assets...
│   └── README.md
├── <project-2>/
│   ├── main.py
│   ├── assets...
│   └── README.md
└── ...
```

## 🚀 Getting Started

1. **Clone the repository**

   ```bash
   git clone https://github.com/mohit-1025/pygame-mini-projects.git
   cd pygame-mini-projects
   ```

2. **Install Pygame**

   ```bash
   pip install pygame
   ```

3. **Run any project**

   ```bash
   cd <project-folder>
   python main.py
   ```

> ⚠️ Always run a project **from inside its own folder** — most projects load images, sounds, and fonts using relative paths.

## 🕹️ Controls

Controls differ from project to project. Each project's **README** documents its own keys, mouse actions, and gameplay rules.

## 🧰 Requirements

- 🐍 Python 3.8+
- 🎮 Pygame 2.x

That's it — happy building and playing! 👾
